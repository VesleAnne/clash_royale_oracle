# The Deck Oracle

Reads a Clash Royale deck as a tarot spread: what the cards say about you, and
what you should beware of. Built from the card database and from what the
community said about the people who play each card.

Card database created on base of clashroyale.fandom.com/wiki 
N.B. Not all of the cards are include. At the moment of creating this Oracle there were no information about Ronin and some other cards. The popularity of the cards is based on the information from royaleapi.com  

An LLM runs **once**, in `build_fragments.py`. Everything after that is
plain assembly — the finished page needs no API key, no server and no network.

---

## Files

| file | what it does | LLM |
|---|---|---|
| `subjects_map.py` | maps Reddit subject names onto cards and pairings | no |
| `oracle_rules.py` | spread positions, shadow card, 14 deck gap rules | no |
| `build_fragments.py` | **one-off pass** — writes `fragments.json` | yes |
| `build_page.py` | bakes everything into one `oracle.html` | no |
| `read_deck.py` | prints a spread in the terminal, for debugging | optional |
| `themes.py` | the layer between single labels and the finished reading | yes |

`subjects_map.py` and `oracle_rules.py` are imported by the others.

## Running it

    pip install google-genai          # or: pip install openai

    python subjects_map.py                # check every subject maps
    python build_fragments.py --dry-run   # see the prompt
    python build_fragments.py --limit 6   # trial on 6 cards
    python build_fragments.py             # the real pass
    python build_page.py                  # -> oracle.html
    open oracle.html

OpenAI instead of Gemini:

    python build_fragments.py --provider openai --model gpt-5 

### Later on

`oracle.html` is self-contained: open it directly, no Python involved. Rebuild
only when the data changes.

    python build_fragments.py   # only if cards.csv or card_traits.csv changed
    python build_page.py        # after any edit to fragments.json

Fragments are cached per card, per pairing and per label, so a rerun only pays
for what is new. Failed batches are never cached, so they retry next time.

## What gets generated

    cards[name]        essence, as_ambition, as_burden, as_everyday,
                       as_shadow, caution  + community (every label attached)
    archetypes[name]   reading, caution, triggers, community
    rules[key]         omen, counsel        (14 deck rules)
    trait_readings[id] reading, shadow      (one per community label, 1:1)

`trait_readings` is the heart of it. Every line of `card_traits.csv` becomes a
statement about the person. The insult is never repeated and never argued with;
only the disposition underneath it is named:

    "low skill card"            -> you do not like to think twice
    "repetitive"                -> you like stability, and return to what works
    "ultra defensive playstyle" -> you do not like to start conflicts

Counts must match. The script prints `CHECK` if any label produced no reading.

## Spread positions

| position | how the card is chosen |
|---|---|
| The Wall | the building with the most hitpoints |
| Hidden Knowledge | the spell with the widest radius |
| The Ambition | the priciest card that hunts only buildings |
| The Burden | the priciest card left |
| The Everyday Self | the cheapest card left |
| The Well-Trodden Path | the highest usage in the deck |
| The Outsider | the lowest usage in the deck |
| The Shadow | the highest usage among cards **not** in the deck |
| The Pairing | any archetype whose trigger cards are all present |

Rarer positions claim their card first, and one card holds at most one role.
An empty position is itself a reading: no building means you built nothing to
stand behind.

## Deck rules

`no_air_defense`, `no_splash`, `no_building`, `no_win_condition`, `heavy`,
`featherweight`, `all_ground`, `swarm_heavy`, `no_cheap_cycle`, `all_slow`,
`all_swift`, `tunnel_vision`, `meta_conformist`, `meta_outsider`.

All computed from columns — pace from `speed`, gaze from `targets`. None is a
hand-written verdict about a particular deck.

## Pairings

Contents are read out of the name where possible (`mega knight hog rider`).
Everything else — `log bait`, `Hog 2.6`, `Lumberloon`, `xbow 3.0` — is written
by hand in `MANUAL` inside `subjects_map.py`. When a fresh export brings a name
the script cannot map, it says so; add it there.

## The page

`build_page.py` embeds `cards.csv` and `fragments.json` into a single HTML file
and ports the whole spread engine to JavaScript. No external scripts, no
`fetch`, no `localStorage`. About 115 KB.

Eight face-down cards; tapping one opens a searchable list of every playable
card with its elixir cost. **Reveal my fortune** lights up once all eight are
chosen. **Read again** clears the spread and draws a new opening line — there
are five, picked at random.

The only thing fetched from the network is two Google fonts. Offline the page
still works, just in a system serif.
